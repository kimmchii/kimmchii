## Hi, I'm Kim 👋

Machine learning engineer working on **Thai speech AI**.

- I fine-tune Thai speech recognition (ASR) models, such as Whisper and Qwen3-ASR, so they work on real phone-call audio.
- I connect speech models to live phone systems (Asterisk, SIP, Genesys) and run them as real-time services.
- I like finding out *why* a model fails before deciding how to fix it.

### 📄 Publication
